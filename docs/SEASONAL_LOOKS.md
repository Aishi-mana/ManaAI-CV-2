# Seasonal looks

Open Wardrobe → Seasons. Each season accepts Assign current look or a saved-look selection. Assignments save immediately but do not change the avatar until Apply look. Clear assignment removes that season's saved selection while retaining current clothing. No new assets are needed: the default outfit can be used in all four slots as a placeholder.

The Northern/Southern calendar chooses displayed month ranges and current-season badge, using Mana's journal timezone. These labels are independent of local weather. This tab applies seasons manually. The separate opt-in Daily looks feature can now schedule random approved outfits.

Assignments snapshot skin, outfit, hairstyle and accessories, with no copied picture/background data. Applying retains current body view/background and uses existing unlock/availability checks; missing/locked items fall back, while the assignment remains available for later. Assignments survive changes/deletion of the named saved look because they retain their own snapshot.

Seasonal looks/calendar are fields in mana.avatar.v1, included in normal backup/restore. Old configs gain no assignments. Only four named seasons are accepted; malformed entries are discarded. Properly aligned new clothing artwork can later be added to the configured avatar folder and reloaded through the avatar Test controls before assigning it. Additional artwork is not generated by this setup.
